# Faiza Khan — Portfolio Website Brief

## What this project is
A personal portfolio website for Faiza Khan,
UX Researcher and Service Designer based in Dubai, UAE.

This is not a typical UX portfolio. It is a personal 
research notebook translated into a website. Every 
element should feel handplaced, noticed, and personal —
not generated or templated.

## Design concept
A spiral-bound physical notebook UI. The website looks 
and feels like opening a real notebook - not a website 
pretending to be one.

Key visual references are saved in:
assets/images/inspiration/

Please look at all images in that folder before 
building anything. Match them as closely as possible.

## Key design rules
- Every sticky note slightly rotated — never straight
- Tape strips on everything pinned to the page
- Margin notes in red Caveat font on left side
- Page number shows as "pg. 01 / ??" — never finished
- Annotations use → and ↳ arrow style in Caveat font
- Red thread SVG connects related research elements
- "beyond" in headline has hand-drawn SVG oval around it
- The notebook never feels complete — it is always 
  being written
